# Warn the camp. Before the attack.

Open ontology-events-animation.html and press Play. ontology-events.mp4 is the captioned 58-second video.

The camp protection scenario follows Wi-Fi flooding, BLE flooding, multiple drone signatures, increasing signal strength, and an urgent camp warning. The ontology represents the semantic model; its changing relationships and attributes over time form the morphology used to interpret escalation.

Presentation time and event time are distinct. Node growth depicts changing observed attributes, not a calibrated probability. Increasing signal strength alone does not establish distance or intent; the scenario interprets the combined pattern in camp context. Incident history persists as the ten-second raw capture window advances.

The scenario warning reads: URGENT: Possible impending attack. Wi-Fi and BLE flooding coincide with multiple strengthening drone signatures. Take immediate protective action under the camp’s emergency plan.

To reproduce, run render_ontology_video.mjs with an isolated Chromium debugging endpoint on local port 9337. It verifies transitions, saves review frames, and exports through MediaRecorder.
