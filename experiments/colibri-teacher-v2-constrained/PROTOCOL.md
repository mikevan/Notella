# Constrained teacher v2 protocol

Freeze three new synthetic A/B pairs before generation. Each pair changes one semantic factor: deliberate disruption versus unresolved outage cause, distinct drone-report roots versus shared upstream root, or corroborated drone identity versus unidentified RF. Timing/window values are newly authored; prepare.py refuses exact normalized overlap with the v6 examples and duplicates within this experiment. The patterns themselves are known and are not independent evaluation families.

The teacher receives explicit compact policy conditions and typed observations, not per-case reference decisions. It must return one decision and a brief rationale per case plus one contrast explanation. Preserve its exact output and finish reason. Score strict JSON shape, decision agreement and existing evidence guards separately. Review the explanation as agent-authored interpretation, not field truth.

Do not admit malformed, incomplete, incorrect, contradictory or unreviewed candidates. Preserve negative outputs; no automatic repair. A successful case is evidence about this constrained task only. No teacher or student weights are changed. A subsequent small-student comparison requires a separately reviewed prospective evaluation set and recorded teaching-material permissions; these six drafts are not a generalization benchmark.
